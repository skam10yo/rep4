# Тлеющий Уголь — сайт кальянного лаунжа

Одностраничный сайт вымышленного лаунжа «Тлеющий Уголь». Это работа для портфолио: тёмная палитра (графит, баклажан, медь и янтарь), зерно и canvas-дым на фоне, свет, который «зажигается» при скролле, и аккуратные анимации на GSAP.

**Стек:** [Astro 5](https://astro.build) со статической сборкой, чистый CSS на переменных, [GSAP](https://gsap.com) + ScrollTrigger, [Lenis](https://lenis.darkroom.engineering). Шрифты Google Fonts — Cormorant Garamond и Manrope, кириллица. Подключены через `@fontsource` и раздаются с домена сайта.

## Запуск

```bash
npm install
npm run photos   # скачать фото по photos.manifest.json и обновить CREDITS.md (один раз)
npm run dev      # http://localhost:4321
npm run build    # статическая сборка в dist/
npm run preview  # посмотреть собранную версию
```

Нужен Node.js 18.20 или новее (на хостинге стоит 22).

## Фото

Фото лежат в репозитории (`src/assets/photos/<slot>.jpg`), на сайте ничего не хотлинкуется. Пайплайн такой:

1. В `photos.manifest.json` для каждого слота указаны `source` (`unsplash` / `pexels` / `pixabay`), `pageUrl`, `url`, `author` и `authorUrl`. Для Unsplash и Pexels в `url` можно положить ссылку на страницу фото, скрипт сам получит прямую ссылку на файл.
2. `npm run photos` скачивает фото, уменьшает до 2400 px по длинной стороне и удаляет EXIF. Затем собирает `public/og-image.jpg` (1200×630) из hero и перегенерирует `CREDITS.md`.
3. На сборке Astro (`<Picture>`) делает AVIF и WebP нескольких ширин с `srcset`/`sizes`. Hero грузится eager с `fetchpriority="high"`, остальные фото — `loading="lazy"`. Alt-тексты берутся из манифеста.

Если какого-то файла нет, `npm run build` падает с понятной ошибкой: заглушек на сайте быть не должно.
Чтобы проверить вёрстку без фото, есть `PHOTOS_OPTIONAL=1 npm run build`. Это только для локальной проверки, не для продакшна.

Требования к фото: без людей крупным планом, без логотипов и брендов.

## Деплой

**Netlify:** подключите репозиторий, настройки подтянутся из `netlify.toml` (`npm run build` → `dist`).
**Vercel:** импортируйте репозиторий, фреймворк Astro определится сам. Настройки лежат в `vercel.json`.

После деплоя задайте переменную окружения `SITE_URL=https://ваш-домен`. Она используется в canonical и абсолютных OG-ссылках, по умолчанию стоит `https://tleyushchiy-ugol.netlify.app`.

## Что внутри

- **18+.** Окно приходит в HTML с сервера, поэтому первый кадр рисуется сразу. Потом JS переводит его в `showModal()`: фокус остаётся внутри окна, Esc не закрывает. «Мне есть 18» сохраняется в `localStorage`. «Выйти» показывает вежливое сообщение, и этот выбор не запоминается.
- **Hero.** Заголовок выезжает по строкам на CSS-анимации, она не ждёт JS и не задерживает LCP. Фото медленно приближается, при скролле работает параллакс, сверху canvas-дым.
- **Фирменный момент.** При прокрутке к бронированию фон плавно уходит от графита к янтарю и разгораются «лампы». Меняется только `opacity` и `transform`, поэтому всё считается на композиторе.
- **Анимации.** Секции проявляются при скролле, карточки идут каскадом (`ScrollTrigger.batch`), у кнопок магнитный эффект (только для мыши) и подсветка под курсором.
- **Меню.** Шесть вкусовых категорий, 18 вкусов, крепость «лёгкая / средняя / крепкая». Фильтры сделаны кнопками с `aria-pressed`, счётчик результатов в `aria-live`.
- **Бронирование.** Все проверки на клиенте:
  - дата не в прошлом и не дальше 60 дней;
  - веранда только с мая по сентябрь;
  - время не ближе 30 минут от текущего;
  - число гостей с лимитом по залу.

  Ошибки выводятся через `aria-describedby`, сверху сводка со ссылками на поля, фокус ставится на первое ошибочное поле. После отправки появляется карточка «Ваша бронь» без обещаний подтверждения. Данные никуда не отправляются.
- **`prefers-reduced-motion`.** Lenis, параллакс, reveal и зерно отключаются, дым рисуется одним статичным кадром, тёплый фон стоит в среднем положении.
- **Производительность.** GSAP, Lenis и дым вынесены в отдельный чанк (около 52 КБ gzip), он грузится в `requestIdleCallback`. Ядро весит около 4 КБ gzip, CSS встроен в HTML. Дым рисуется на половинном разрешении примерно с 30 fps и ставится на паузу вне экрана.

## Проверки

- Ширины 375, 768 и 1440 px: горизонтального скролла нет. Скриншоты сняты через Playwright.
- Lighthouse 12, прогон локально на сервере с brotli:
  - Mobile: Performance 93–95, Accessibility 100, Best Practices 100, SEO 100.
  - Desktop: 100 / 100 / 100 / 100.
- Замеры сделаны **без фото** (`PHOTOS_OPTIONAL=1`). С настоящим hero-фото LCP будет считаться по картинке. После `npm run photos` прогоните Lighthouse ещё раз.
